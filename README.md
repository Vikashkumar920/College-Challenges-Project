# Challenge 3 – Recently Viewed Products Tracker

## Overview
This project tracks the products recently viewed by a user. Whenever a product is viewed, it is added to the viewing history. The system maintains only the latest 5 viewed products and updates the history dynamically.

## Features
- Display all available products
- Track recently viewed products
- Move re-viewed products to the top
- Maintain only the latest 5 viewed items
- Clear viewing history with one click
- Dynamic UI updates using JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## How It Works
1. Products are loaded from the store dataset.
2. User clicks on "View Product".
3. Product is added to the recently viewed list.
4. If the product already exists in history, it is moved to the top.
5. Only the latest 5 viewed products are stored.
6. User can clear the history at any time.
